# Nemo

Signed and notarized macOS builds of Nemo, a browser-shaped terminal.
Apple silicon only.

**[Download the latest Nemo.dmg](https://github.com/raphaland/nemo-releases/releases/latest/download/Nemo.dmg)**

Every release is built, signed and notarized by CI; `checksums.txt`
alongside each DMG carries its SHA-256. Nemo itself is not open
source; this repository exists to host releases and track issues.
